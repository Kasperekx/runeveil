# World animals + pickups sync

Date: 2026-08-01_21-54

## Goal
Animals and world pickups live in Colyseus room state (memory only). Survive page refresh; reset on server restart. Server-authoritative kill/collect.

## Approach
- Schema: `animals`, `pickups` maps
- Server tick ~10 Hz for wander + respawn
- Messages: `attackAnimal`, `collectPickup`, `dropItem`, `save` (player pos + slots)
- Client renders from state; no local spawn set
