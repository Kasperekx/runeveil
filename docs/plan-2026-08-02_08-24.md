# Player stats + SQLite + character panel

Date: 2026-08-02_08-24

## Goal
Per-player attributes (WoW-core), persisted in SQLite, affecting HP/damage. Character panel (C) with paper-doll + stats. Class catalog for future classes (warrior default).

## Approach
- `src/data/classes.yaml` — base attrs + derived formulas
- `PlayerRepository` (SQLite) replaces JSON file store; migrate existing `players.json` once
- Colyseus `PlayerState` syncs identity + attrs + derived `attackPower` / `maxHp`
- Client: Character panel toggle on KeyC; PlayerHud name from server

## Out of scope (v1)
- Equipping items into paper-doll slots
- Leveling / XP gains
- Postgres
