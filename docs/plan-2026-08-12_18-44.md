# Plan: Animacje chodzenia skeletona (4 kierunki)

Date: 2026-08-12_18-44

## Cel
Wygenerować 4-klatkowe cykle chodzenia dla skeletona we wszystkich 4 kierunkach, wiernie dopasowane do istniejących idle (`skeleton-{east,west,north,south}.png`), bez użycia `tmp/imagegen`.

## Kontekst
- Idle: 124×124 RGBA, black/alpha tło, pixel art undead warrior (miecz, pauldron, skórzane paski).
- Loader: `layout: cardinal-static` → ten sam kadr idle = walk (brak animacji).
- Konwencja innych creature: 4 klatki walk / kierunek (`walk-side|down|up-{1..4}`), opcjonalnie osobne `walkLeft`.
- East/west są **osobno autorowane** (nie mirror) — walk left też musi być osobny zestaw.

## Zakres (KISS / YAGNI)
**W scope**
1. 4×4 = **16 klatek** walk z `GenerateImage` + `reference_image_paths` = odpowiedni idle kierunkowy.
2. Zapis bezpośrednio do `public/assets/creatures/skeleton/` (pomijamy `tmp/imagegen`).
3. Nazewnictwo cardinal: `skeleton-walk-{south,north,east,west}-{1..4}.png` (124×124, nearest-friendly).
4. Nowy layout loadera `cardinal-animated` (idle cardinal + walk 1..4 per kierunek, `idleLeft`/`walkLeft` = west).
5. `creatures.yaml`: `layout: cardinal-animated` dla skeletona.
6. Idle pozostają bez zmian jako `skeleton-{east,west,north,south}.png`.

**Poza scope**
- Dead sprite (zostaje south + deadAngle)
- Attack / hit animacje
- Zmiana `animFps` / speed / renderScale
- Proceduralne warp’y pikseli zamiast generacji z reference

## Podejście generacji
Dla każdego kierunku osobno, z **oryginalnym** idle jako jedyną referencją:
1. **south (down)** ← `skeleton-south.png` — front, naprzemienne nogi, lekki bob, swing miecza vs wolnej ręki.
2. **north (up)** ← `skeleton-north.png` — tył, te same zasady (plecy / pochwa).
3. **east (side/right)** ← `skeleton-east.png` — profil w prawo, stride nóg, swing miecza.
4. **west (side/left)** ← `skeleton-west.png` — profil w lewo, osobne klatki (nie flip east).

Wymagania klatek: ten sam styl/paleta/proporcje co reference; czarne lub przezroczyste tło; postać wycentrowana; loopable 1→2→3→4→1.

## Integracja loadera
`creatureSpritePaths(..., "cardinal-animated")`:
- idleSide/walkSide ← east + walk-east-1..4
- idleLeft/walkLeft ← west + walk-west-1..4
- idleDown/walkDown ← south + walk-south-1..4
- idleUp/walkUp ← north + walk-north-1..4
- dead ← south, deadAngle 90

## Krytyka zasad
- **KISS:** jeden nowy layout, te same 4 klatki co boar/deer.
- **YAGNI:** bez stripów, bez ataku, bez martwego kadru.
- **SRP:** assety + ścieżki loadera; logika `WanderingAnimal` bez zmian.
- **DRY:** reuse `CreatureSprites.load` / `idleLeft`/`walkLeft`.

## Ryzyka
- Drift stylu AI między klatkami → regeneracja pojedynczych klatek z tym samym reference.
- Rozmiar ≠ 124×124 → `sips` resize / crop po generacji.
- Niespójny loop → ręczna korekta kolejności 1..4.
