# Plan: Placeable campfire — produkcyjny prop def

Date: 2026-08-12_22-13

## Cel
Ujednolicić runtime palenisko z wzorcem mapowych propów: jeden katalog (anchor, collider, light, interaction, animacja), bez rozrzuconych magic numbers.

## Podejście
1. `src/data/placeableCampfire.yaml` — SSOT (jak `creatures.yaml`), client + server.
2. Helper `collidersForProp(def, x, y)` — ten sam pipeline co `collidersFromMap`.
3. `Environment.upsertRuntimeCampfire` czyta def (anchor 0.5/0.5, zIndex=y, colliders, interaction, idle frames).
4. Light z `def.light` przez `LightSystem.upsertLight`.
5. Placement + WorldRoom walidacja z `collisionRadius` / `placeRange` z yaml.

## Krytyka
- KISS: jeden plik danych, bez nowego package.
- YAGNI: bez DB, bez ambient particles (animowane klatki wystarczą).
- DRY: collidery i light z def, nie copy-paste 16/162/18.
