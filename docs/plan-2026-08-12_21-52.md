# Plan: Stawianie paleniska (cooking placement mode)

Date: 2026-08-12_21-52

## Cel
Z panelu profesji (Gotowanie) wejść w tryb stawiania paleniska jak w WoW / New World: ghost pod kursorem w czasie rzeczywistym → klik = postaw → działa jako cooking station.

## Kontekst
- Assety: `public/assets/props/campfire/campfire-1..9.png` (animacja).
- Dziś gotowanie tylko przy mapowych `cookingStations` + prop `cooking-campfire`.
- Brak istniejącego build/ghost mode.

## Zakres (KISS / YAGNI)
**W scope (v1)**
1. W `ProfessionsPanel` (gdy aktywne Gotowanie): przycisk „Postaw palenisko” z ikoną `campfire-1.png`.
2. Tryb stawiania (`CampfirePlacementMode`):
   - zamyka panel / nie blokuje kamery,
   - ghost sprite pod kursorem (world),
   - zielony/czerwony tint (wolne vs zajęte),
   - LMB = postaw, RMB / Esc = anuluj.
3. Serwer: `placeCampfire {x,y}` — walidacja zasięgu od gracza, playable bounds, kolizje, limit **1 palenisko / gracz**.
4. Broadcast `campfirePlaced` / sync przy joinie; klient dokłada runtime prop + cooking interaction + light/ambient.
5. `isAtCookingStation` uwzględnia postawione paleniska.
6. Stawianie nowego usuwa poprzednie tego gracza (replace).

**Poza scope**
- Koszt materiałów / przepis craft „palenisko”
- Trwałość w DB między restartami serwera (v1: w pamięci mapy / sesji)
- Obrót, snap do siatki Tiled, housing UI
- Stawianie innych propów

## Podejście
1. **UI:** przycisk w railu cooking → `onStartPlaceCampfire()`.
2. **Client placement:** Pixi ghost w warstwie world; `screenToWorld`; walidacja lokalna + request do serwera.
3. **Server:** mapa runtime `placedCampfires: Map<id, {owner, x, y}>`; przy place: usuń stare ownera → dodaj → broadcast.
4. **Environment:** `addRuntimeCampfire(id, x, y)` / `removeRuntimeCampfire(id)` — sprite animowany z `campfire-1..9`, interaction cooking, station radius ~96.
5. **CookingStationInteraction:** range check obejmuje runtime stations (przez Environment.interactions).

## Krytyka zasad
- **KISS:** jeden prop, jeden limit, jeden tryb.
- **YAGNI:** bez DB persist i bez craft cost na start.
- **SRP:** placement mode ≠ panel ≠ Environment.
- **DRY:** reuse `CookingStationInteraction` + istniejący craft.

## Ryzyka
- Desync colliders vs ghost → serwer ostateczny.
- Zbyt ciasny zasięg place → toast „za daleko”.
- Animacja 9 klatek vs stary single texture — OK w Environment animatedProps.
